# المحاسب الذهبي — Android أصلي

مشروع محاسبة ومخزون يعمل محلياً على Android باستخدام Kotlin وRoom/SQLite، مع واجهات عربية RTL. لا يستخدم WebView أو HTML/JavaScript كتطبيق بديل.

## ما هو موجود حالياً
- لوحة تحكم تقرأ ملخص المبيعات والمشتريات والذمم وقيمة المخزون من قاعدة البيانات.
- إعداد المنشأة عند أول تشغيل، ثم إنشاء حساب مدير نظام وتسجيل دخول بكلمة مرور مُجزّأة مع salt.
- أدوار وصلاحيات: مدير النظام، مدير، محاسب، أمين صندوق، أمين مخزن.
- إدارة المستخدمين وسجل تدقيق للعمليات المحاسبية والمخزنية.
- حسابات وكشف حساب ودليل الحسابات وتصنيفات مرنة للحسابات مع ربط متعدد، وتعديل لون/أيقونة التصنيف وترتيبه.
- فواتير بيع وشراء، سندات قبض وصرف، قيود يومية وافتتاحية، تقارير ميزان المراجعة وقائمة الدخل والمركز المالي.
- أصناف، تسوية مخزون، إدارة مستودعات، تحويلات مخزنية ذرّية بحركتي صرف/توريد، سجل التحويلات ورصيد حسب المستودع.
- نسخ احتياطي واستعادة مع فحص سلامة قاعدة البيانات.
- تصدير تقارير PDF.
- Room migrations حتى الإصدار 5، مع اختبارات المحرك والمخزون وتدفق الفواتير في GitHub Actions.

## التحقق من البناء
آخر بناء موثّق قبل ميزة تقارير المستودعات: [GitHub Actions run 79](https://github.com/almasawa91-hub/Golden/actions/runs/38636667548) — الاختبارات وLint وبناء APK ورفع Artifact نجحت. يجب إعادة التحقق من آخر commit بعد أي تغيير قبل اعتبار النسخة صالحة.

## ما يزال مطلوباً قبل اعتبار التطبيق منتجاً نهائياً
- اختبارات قاعدة بيانات فعلية للترحيل من الإصدارات السابقة، والنسخ الاحتياطي/الاستعادة، والتحويل بين المستودعات.
- مراجعة شاملة لمنطق المحاسبة والمخزون على سيناريوهات واقعية، خصوصاً المرتجعات والضرائب والعملات والتكلفة.
- شاشات كاملة لإدارة وحدات القياس والباركود والصلاحية والجرد والتسويات المتقدمة.
- فلاتر التقارير حسب التاريخ والحساب وتوسيع التصدير والطباعة الحرارية 58/80 مم.
- تحسين الواجهة ومراجعة الاستخدام على أحجام شاشات مختلفة.
- بناء Release موقّع واختباره على جهاز Android فعلي قبل النشر. ملف CI الحالي هو APK تجريبي Debug وليس إصداراً منشوراً.

## البناء السحابي
افتح تبويب Actions في المستودع، واختر أحدث تشغيل مكتمل، ثم نزّل Artifact باسم `debug-apk`. لا توجد مطالبة بأن التطبيق اكتمل نهائياً حتى تُنجز قائمة التحقق أعلاه.
