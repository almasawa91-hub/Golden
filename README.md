# المحاسب الذهبي — النسخة الأصلية (Native)

هذا مشروع التحويل من WebView إلى تطبيق أندرويد أصلي. **هذه هي المرحلة الأولى فقط.**

## حالة التنفيذ (بصدق)
| المرحلة | الحالة |
|---|---|
| 1. تحليل الواجهة والوظائف | وثائق في docs/ |
| 2-3. قاعدة البيانات وطبقة البيانات | Room: حسابات، قيود، أصناف، مخازن، حركات مخزون، فواتير، عملات، إعدادات |
| 4. محرك المحاسبة والمخزون والتقارير | قيد مزدوج، ضرائب، خصومات، مرتجعات، متوسط متحرك، عملات، تقارير تُحسب من القيود، مع اختبارات |
| 5-8 (جزئي) | واجهة أصلية: الرئيسية، فاتورة بيع/شراء، الحسابات وكشف الحساب، سندات القبض والصرف، القيد اليومي والافتتاحي، دليل الحسابات، الأصناف، ميزان المراجعة، قائمة الدخل، المركز المالي، المخزون، حركة الصندوق، إعدادات الضريبة والكمية السالبة |
| لم يبدأ | الصلاحيات والمستخدمون، كلمة السر والتشفير، النسخ الاحتياطي، الطباعة، الباركود، الترحيل من WebView، Google Drive وواتساب، العملات والمخازن (شاشات)، الأصناف المتقدمة (وحدات/صلاحية)، عرض سعر وطلب شراء، الجرد والتحويل والتسوية، تصفية التقارير بالتاريخ والحساب (المنطق جاهز في المستودع دون واجهة) |

لم يُبنَ المشروع ولم تُشغَّل الاختبارات في بيئة التطوير التي كتبته (لا Gradle ولا Android SDK). أول تشغيل لـ GitHub Actions هو أول تحقق فعلي؛ أرسل أي خطأ يظهر وسيُصلح.

## التشغيل
1. ارفع كل محتويات المجلد (بما فيها .github) إلى مستودع GitHub.
2. تبويب Actions ثم CI: يختبر ويفحص ويبني debug APK.
   للإصدار: أضف أسرار KEYSTORE_BASE64 و KEYSTORE_PASSWORD و KEY_ALIAS و KEY_PASSWORD ثم أنشئ وسم v1.0.0 لتشغيل Release (APK + AAB مع فحص عدم وجود WebView).
3. المخرجات: تقارير الاختبار في Artifacts.

التطبيق الحالي العامل (WebView) باقٍ في مشروع GoldenAccountant-Android.zip إلى أن تكتمل النسخة الأصلية.
