# خريطة الواجهة (من الفيديوهات)
Home: شريط أزرق متدرج، ☰ / عنوان / مشاركة / جرس؛ أزرار المبيعات والمشتريات والحسابات وقبض/صرف؛ قوائم زرقاء منسدلة؛ شريط سفلي باسم المخزن.
قوائم: رأس أعمدة مسطّر، «لا توجد نتائج...»، زر + دائري أبيض بالشريط السفلي.
الفاتورة: مرتجع، آجل (مفتاح وردي)، المخزن، العملة، الطرف، التاريخ، رقم#، ملاحظات، حقل «اكتب اسم الصنف»، جدول، شريط الإجماليات.
الحوارات: عنوان وسطي، حقول بخط سفلي وردي عند التركيز، أزرار إضافة/إلغاء/إغلاق.
الإعدادات: قائمة بأيقونات دائرية زرقاء، صفوف مفاتيح تبديل مع وصف صغير.
