# جرد الوظائف الحالية (Feature Inventory)
المصدر: قاعدة inv.db + فيديوهي التطبيق الأصلي (محاسب سوفت) + نسخة WebView الحالية.

- الرئيسية: المبيعات، المشتريات، قبض/صرف، الحسابات + قوائم: عمليات مخزنية، قيود وحسابات، أصناف، العملات، التقارير
- الفواتير: بيع/شراء، آجل/نقد، مرتجع، مخزن، عملة، عميل/مورد، ملاحظات، خصم تجاري (مبلغ/نسبة)، ضريبة، رسوم أخرى، مدفوع/متبقي، حفظ/طباعة/مشاركة/حذف
- فاتورة عرض سعر، طلب شراء
- السندات: قبض/صرف بعدة قيود وعملات
- قيد يومي، قيد افتتاحي، حركة الصندوق، كشف حساب، دليل الحسابات، إقفال سنوي
- الحسابات: عملاء/موردون/صناديق/بنوك/مصروفات/إيرادات، سقف الحساب
- المخزون: صرف، توريد، تحويل، تسوية، جرد، إضافة مخزن
- الأصناف: الأصناف، أسعار البيع، وحدات الصنف، مجموعة الصنف، باركود
- العملات: إضافة عملة، سعر العملات
- التقارير: حركة الأصناف، ميزان المراجعة، قائمة الدخل، المركز المالي، المخزون المتبقي، أرصدة الحسابات، أرباح الأصناف، العمليات اليومية، القيود اليومية، حركة الصندوق، حركة الحسابات، إجمالي التصنيفات، فوارق العملات، رأس المال العامل، الربح على مستوى العميل، المبيعات/المشتريات حسب الصنف، تفاصيل حركة الأصناف
- الإعدادات: البيانات الشخصية، الطباعة، الأمان (كلمة سر)، المستخدمون والصلاحيات، التصنيفات، مجموعة الصنف، وحدات القياس، حفظ البيانات، الطابعة الحرارية، الضريبة، طباعة باركود الأصناف، الإشعارات، خيارات أخرى، تفعيل الاشتراك
- التنقل: سحب من الحافة/زر الرجوع، قوائم ⋮ منبثقة، نوافذ حوار
- غير موجود في المرجع ويحتاج قرارا: الفوترة الإلكترونية، المزامنة، الدردشة، Google Drive، WhatsApp
